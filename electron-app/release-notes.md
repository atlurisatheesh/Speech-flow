## Speech-Flow v1.0.0 - Windows Desktop App

AI-Powered Voice Assistant for Windows

### Features
- Wake word detection (hey flow)
- Real-time speech-to-text
- AI-powered text formatting
- Multilingual support (English, Telugu, Hindi, Tamil)
- Works in any application (Ctrl+Win to activate)
- Voice profiles for different contexts

### Installation
1. Download Speech-Flow Setup 1.0.0.exe
2. Run the installer
3. Launch Speech-Flow from the Start Menu
